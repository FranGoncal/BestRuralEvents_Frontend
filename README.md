# BestRuralEvents_Frontend (Flutter)

This project includes a **Flutter-based mobile application** that connects to a microservices backend.

Users can browse events, view details, purchase tickets, and manage their profiles through a clean and intuitive interface.

## Features

- Event discovery and search  
- Event details and reviews  
- Ticket purchasing and management  
- User authentication and profile  
- Favorites and personalized content  

The app communicates with the backend via the **API Gateway**, consuming REST APIs and handling authentication using JWT tokens.

Built with Flutter, the app demonstrates cross-platform mobile development integrated with a scalable microservices architecture.
